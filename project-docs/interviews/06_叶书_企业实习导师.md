1. 交接冲突根源是口径不一致：企业重设备点检与交接，学校评价偏理论，任务口径须共同校准（f51）

4. 下游反馈须关联原业务编号与当时资料版本，由企业导师受理、教务管理员核实，未确认前不承诺赔偿（f54）
