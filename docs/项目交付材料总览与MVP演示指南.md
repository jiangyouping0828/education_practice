## 二、MVP 演示指南（约 10 分钟）

### 准备（2 分钟）

```bash
cd intern-assistant
pip install -r requirements.txt
copy .env.example .env        # 填入自己的 DeepSeek API Key
scripts\run.bat               # Windows 启动；Linux/macOS 用 bash scripts/run.sh
```

浏览器打开 `http://127.0.0.1:8000`。

### 演示 1：制度问答 + 拒答纪律（学生身份）

用学号 `20230101`（密码 `123456`）登录学生端：

1. 问「**实习生请假超过 3 天需要什么流程？**」→ 流式回答，末尾附【制度文档】引用来源；
2. 问「**公司允许带宠物上班吗？有托管补贴吗？**」→ 回答"制度文件中未找到相关规定"，
   **不编造**（这是系统的核心纪律：查不到就拒答）。

### 演示 2：智能体办申请 + 人工确认闸门（约 3 分钟）

继续在聊天框输入：

> 帮我提交一个请假申请，从下周一开始到周三，感冒就医。

观察三步：① 智能体先调 `validate_apply_material` 服务端校验字段 →
② 生成**草稿卡片**（不自动提交），列出开始/结束日期与事由 →
③ 必须人工点「确认提交」，票据核销后才真正落库。
点「取消」或等 10 分钟票据过期，申请都不会生效——**模型无法替学生按下提交键**。

### 演示 3：数据隔离（安全）

- 退出，换学号 `20230102` 登录 → **看不到**上一个学生的任何会话记录；
- 尝试直接访问上一个学生的会话地址 → 403 拒绝。

### 演示 4：管理后台（管理员身份）

用管理员账号登录 `http://127.0.0.1:8000/login`：

- **仪表盘**：会话数、消息量、知识库切片、申请单统计；
- **问答记录**：全部学生会话列表，点开任意会话可看到**每轮工具调用轨迹**；
  每次查看都会记入审计日志，页面顶部明示"该会话累计被查看 N 次"；
- **知识库**：上传一份新的制度 Markdown，系统自动切片入库，学生端立即可问答。

### 演示 5：质量证据（1 分钟，可选）

```bash
cd intern-assistant
pip install pytest && pytest tests/ -q     # 138 passed
python -m intern_assistant.cli eval        # 30 条评测用例静态审计 + 离线回放
```

## 三、技术要点速览

- **技术栈**：Python 3.10+ / FastAPI / SQLite / SSE 流式 / DeepSeek API
- **检索**：500 字切片 + BM25 关键词 + 向量余弦（哈希本地向量或远程 embeddings）混合
- **智能体**：Function Calling + 自建 Harness 执行循环（最多 5 轮），全程留痕 `agent_rounds`
- **三层防线**：提示词纪律（软）→ 规则引擎硬校验（中）→ 票据闸门唯一核销（硬）
- **工程质量**：ruff + pre-commit + CI 三版本矩阵 + Conventional Commits + ADR
